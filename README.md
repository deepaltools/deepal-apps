# Deepal Apps

### 📣 [Telegram-канал: @deepal_tools](https://t.me/deepal_tools) &nbsp;·&nbsp; ❤️ Поддержать проект: [Tribute](https://web.tribute.tg/d/PI5) или [Boosty](https://boosty.to/deepaltools/donate)

Каталог приложений, который читает **Deepal Store** на головном устройстве автомобиля.

Здесь только открытые данные: список приложений, их описания, иконки и отпечатки
сертификатов подписи. Ни исходников, ни сборок, ни ключей.

## Зачем отдельный репозиторий

Магазин в машине ходит сюда без всякой авторизации: у человека за рулём нет ни аккаунта
GitHub, ни токена. Значит, каталог обязан лежать в открытом месте — и лежать отдельно от
всего, что открытым быть не должно.

## Что внутри

| | |
|---|---|
| `catalog.json` | каталог для Deepal Store 0.23 и старше (схема 1) |
| `catalog-full.json` | каталог для Deepal Store 0.24 и новее (схема 2) |
| `icons/` | значки приложений, 512×512 |

## Каталог

Репозитории раздачи открыты: магазин в машине ходит туда без авторизации, у человека за
рулём нет ни аккаунта, ни токена. Тестового канала больше нет: новые сборки проверяются в
машине установкой с компьютера, а магазин раздаёт только готовое.

Адрес, по которому читает магазин:

```
https://raw.githubusercontent.com/deepaltools/deepal-apps/main/catalog.json
```

Каждое изменение проверяется: формат, обязательные поля, отпечаток подписи.

## Две схемы

Магазин 0.24 и новее читает `catalog-full.json`, а если его нет — `catalog.json`. Магазины
0.23 и старше знают только `catalog.json` и вторую схему не поймут, поэтому смысл
`catalog.json` не меняется: в нём только бесплатные приложения с релизами GitHub.

Вторая схема — это всё то же самое плюс приложения с сервера Deepal Tools (Deepal
Cockpit, Яндекс Навигатор, Яндекс Музыка). У них источник
`{"kind": "deepaltools", "app": "cockpit" | "yandexnavi" | "yandexmusic"}`: магазин
берёт лицензию у Cockpit на этой же машине и с ней просит у сервера ссылку на файл.
У Яндекса есть языковые варианты (`variants`): «Русский» и «Как в машине».

Новое бесплатное приложение дописывается в оба файла: `catalog.json` и `catalog-full.json`.
