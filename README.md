# Deepal Apps

Каталог приложений, который читает **Deepal Store** на головном устройстве автомобиля.

Здесь только открытые данные: список приложений, их описания, иконки и отпечатки
сертификатов подписи. Ни исходников, ни сборок, ни ключей.

## Зачем отдельный репозиторий

Магазин в машине ходит сюда без всякой авторизации: у человека за рулём нет ни аккаунта
GitHub, ни токена. Значит, каталог обязан лежать в открытом месте — и лежать отдельно от
всего, что открытым быть не должно.

## Что внутри

| | |
|---|---|
| `catalog.json` | обычный канал: то, что готово для всех |
| `catalog-<знаки>.json` | тестовый канал: всё, включая ещё не готовое |
| `icons/` | значки приложений, 512×512 |

## Два канала

Репозитории раздачи открыты: магазин в машине ходит туда без авторизации, у человека за
рулём нет ни аккаунта, ни токена. Но «лежит открыто» и «люди про это знают» — разные
вещи, и что человек видит в списке, решает каталог, а не репозиторий.

Поэтому каталога два. В обычном перечислено готовое. В тестовом — всё, включая
недоделанное; он включается переключателем в самом магазине, на экране «О программе».
Так новое приложение проверяется в настоящей машине настоящим путём — с загрузкой,
проверкой подписи и установкой, — а не в обход магазина через провод.

Имя файла тестового каталога не случайное: оно выводится из кода, который спрашивает
магазин. Внутри приложения нет ни кода, ни этого адреса — правильный код даёт адрес, по
которому что-то лежит, любой другой ведёт в никуда. Переименовывать файл руками не
нужно: он назван так, как назван, специально.

Адрес, по которому читает магазин:

```
https://raw.githubusercontent.com/deepaltools/deepal-apps/main/catalog.json
```

Каждое изменение проверяется: формат, обязательные поля, отпечаток подписи.
